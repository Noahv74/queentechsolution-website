Tool 02

Lock wiring: NO / NC / COM

The most common mistake on site. A magnetic lock needs power to stay locked, so it goes on NC. An electric strike needs power to open, so it goes on NO.

Magnetic lock (fail-safe) + exit button + break glass

+12VGND / 0VSwitched lock powerExit button signal
FromToWhy
PSU +12VReader +12V and Reader COMPowers the reader and feeds the lock relay
Reader NCBreak glass COM → Break glass NC → Maglock +Power flows to the lock until the relay opens or the glass is broken
Maglock −PSU GNDReturn path
Exit button NO / COMReader PUSH / GNDPressing the button tells the reader to release the door
Fire alarm relay (NC)In series with Maglock +, like the break glassAll doors release on fire alarm
Magnetic lock → NC

Fail-safe: locked while powered, opens when power is cut. Required on escape routes.

Electric strike / bolt → NO

Fail-secure: stays locked without power, opens when the relay closes. Check the local fire rules first.

Protect the relay

Fit a diode (1N4007) across the lock, stripe to +, unless the lock has one built in. Use a separate PSU output for the lock if it draws more than the reader relay rating.
